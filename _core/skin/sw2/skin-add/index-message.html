SW2.5 用 / SW2.0 用

注意書き

利用方法

ログインしないとデータの登録はできません。サーバのメンバーなら Discord のアカウントでログインできます
質問・要望などは Discord サーバ上か Twitter でツール管理者に送ってください

データについて

ルールブックやサプリメントの魔物データ・アイテムデータをそのまま登録しないでください
キャラクター画像は著作権・肖像権的に問題ないものを使用してください
この辺のルール違反があった場合は特に予告なく削除します
アニメやゲームのスクショの場合、管理側で判断がつかない場合があります。
判断がつかない場合、安全側に倒すために削除することがほとんどとなります。
大丈夫な根拠がある場合はキャラクターシートのその他メモ欄などを使って説明頂けると助かります
エネミーデータのみ作成・編集することを想定しています。
ルールブックやサプリメント掲載の魔物データをそのまま登録してください。
その際には記法なども可能な限り公式に揃えてください。
管理者が関わっている複数のコミュニティで共用するものとして作っています。
制作者欄は空欄にしておいたほうが精神衛生上いいかもしれません。
また、互いの作ったデータを利用できるようにする前提なのでデータは全て開示し、一覧に表示してください。
おまけ：インフィニットコロッセオのランダムエネミー生成ツール
